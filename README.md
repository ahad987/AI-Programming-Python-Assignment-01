
# AI Programming With Python — Assignment 01

This repository contains my solutions to **Assignment 01** from the AI Programming With Python course. The assignment focuses on fundamental Python programming concepts and problem-solving skills.

## 📚 Topics Covered

- Lists and list operations
- User input and type conversion
- Conditional statements (`if`, `else`)
- Loops (`for`)
- Functions and return values
- Exception handling (`try-except`)
- File handling and reading text files
- String manipulation and slicing
- Palindrome checking

## 📝 Assignment Questions

### Question 1: Divisibility Check
Extract numbers that are divisible by 4 but not divisible by 8 from a list of integers.

**Sample Input**
```text
4 6 8 12 16 20 24 28
```

**Expected Output**
```text
[4, 12, 20, 28]
```

### Question 2: Compute Ratio
Write a function `compute_ratio(x, y)` to calculate `(x + y) / (x * y)` and handle division-by-zero errors.

**Sample Input**
```text
5 0
```

**Expected Output**
```text
Error: Division not possible
```

### Question 3: Find the Longest Word
Read a text file and find the longest word in its content.

**Sample File Content (`data.txt`)**
```text
Python is a wonderful language for machine learning.
```

**Expected Output**
```text
wonderful
```

### Question 4: Words Starting with Vowels
Convert a sentence into a list containing only words that start with a vowel (`a`, `e`, `i`, `o`, or `u`), ignoring case.

**Sample Input**
```text
An apple a day keeps the doctor away
```

**Expected Output**
```python
['An', 'apple', 'a', 'away']
```

### Question 5: Palindrome Checker
Check whether a word is a palindrome, ignoring uppercase and lowercase differences.

**Sample Input**
```text
Radar
```

**Expected Output**
```text
Palindrome
```
